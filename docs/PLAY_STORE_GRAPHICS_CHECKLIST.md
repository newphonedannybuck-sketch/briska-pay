# Briska Pay Play Store Graphics Checklist

## Required Assets
- 512 x 512 app icon.
- 1024 x 500 feature graphic.
- Phone screenshots.
- Promotional copy.

## Optional Assets
- Tablet screenshots.

## Screenshot Plan
1. Home dashboard.
2. Add Day.
3. Entries.
4. Reports.
5. Calendar.
6. Excel Export.
7. Settings and Themes.
8. Backup and Restore.

Do not use fake screens or show features that Briska Pay does not contain.
