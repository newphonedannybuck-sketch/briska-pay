# Briska Pay Beta Test Plan

## Fresh Installation
- Install Briska Pay.
- Complete onboarding.
- Close and reopen the app.
- Confirm settings remain.

## One-Week Test
- Add five work days.
- Mix Home and Away days.
- Add an allowance.
- Add a job uplift.
- Edit one day.
- Delete and recreate one day.

## Special Days
- Add Holiday.
- Add Unpaid Day Off.
- Verify totals.

## Pay Periods
- Weekly.
- Fortnightly.
- Four-weekly.
- Monthly.
- Last Friday of month.

## Export
- Export Excel.
- Open in Excel.
- Open in Google Sheets.
- Confirm whole numbers do not show trailing dots.
- Share an export.
- Rename an export.
- Delete an export record.

## Data
- Create backup.
- Delete entries.
- Restore backup.
- Confirm entries return.

## Security
- Enable biometrics.
- Background and reopen.
- Disable lock.

## Themes
- Light.
- Dark.
- System.

## Reliability
- Force-stop.
- Restart phone.
- Test low-storage behaviour where practical.
- Cancel file pickers.
- Deny permissions where applicable.
